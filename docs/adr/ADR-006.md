# ADR-006: Dedicated Backtest Workbench & AI Strategy Studio with Standardized JSON Schema

**Status:** Accepted

## Context
During initial development, the Backtest form was embedded directly on the main Market Dashboard. As features expanded to include 12-column trade accounting (STT, Pair/Coin, Direction, Entry Time/Price, Initial Capital $100, Stop Loss, Take Profit, Exit Time/Price, Transaction Fee, 5bps Slippage, Net Profit $ and %), date range pickers (From-To), and natural language prompt strategy generation, the single-page dashboard became cramped and overloaded. Additionally, users required a structured studio to convert natural language prompts and web URLs into validated, reproducible strategy definitions before execution.

## Decision
1. **Dedicated Route Separation**:
   - Transformed the root `/` page into a focused **Multi-Timeframe Real-time Monitoring Center** (4 live candlestick charts: 15m, 1h, 4h, 1d).
   - Migrated and expanded all backtesting capabilities into a dedicated **Backtest Workbench** tab at `/backtest`.
   - Created a standalone **AI Strategy Studio** at `/strategy-studio` implementing a 4-column workflow: Prompt/Web Input $\rightarrow$ Parsed Rules $\rightarrow$ Standard JSON Schema $\rightarrow$ Validation & Strategy Library Persistence.
2. **Financial-Grade Trade Accounting**:
   - Enforced fixed initial capital (`$100.00` default), realistic transaction fees (`0.05%`), and market slippage simulation (`5 basis points = 0.05%`).
   - Integrated strict Stop Loss (%) and Take Profit (%) exit triggers directly into `TradeSimulator`.

## Consequences
- **Positive:** Maximum visual clarity. Traders have a spacious, full-width canvas for deep technical analysis, zoomable Buy/Sell markers, and comprehensive 12-column trade inspection.
- **Positive:** Separation of Concerns (SoC). Strategy authoring/prompt parsing (`/strategy-studio`), historical simulation (`/backtest`), and live market observation (`/`) operate on distinct interfaces without cognitive clutter.
- **Positive:** Reproducibility. Strategies created via the studio are saved with explicit JSON schemas, versions, and tags in SQLite, enabling exact replication of backtest experiments.
- **Negative:** Requires multi-tab client routing via `react-router-dom` and state passing across views when navigating from Studio to Backtest.
